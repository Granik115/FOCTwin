# Локальные программы FOCTwin 0.5.0b1

## Назначение

`.focscript` — читаемый UTF-8 файл с последовательностью уже существующих команд прошивки и
задержек. FOCTwin не преобразует высокоуровневые слова в управление мотором: Commander-строка
после проверки формата передаётся в Serial без изменения.

## Грамматика

```text
program     := line*
line        := blank | comment | wait | firmware_command
comment     := optional_space "#" any_text
wait        := optional_space "WAIT" space nonnegative_seconds optional_space
firmware_command := active_device_id printable_ascii_without_whitespace*
```

- `WAIT` регистронезависим и задаёт секунды, например `WAIT 0.25`.
- Пустые строки и полнострочные комментарии `# ...` не выполняются.
- Inline-комментарии после команды не поддерживаются: вся непустая строка является командой.
- Команда должна быть одним ASCII-токеном и начинаться с активного ID мотора, по умолчанию `A`.
- Валидатор проверяет безопасный формат, но не выдумывает и не подтверждает opcode прошивки.
- В версии 0.5.0b1 нет переменных, арифметики, условий, циклов, include и shell-команд.

Ограничения одного файла:

- размер не более 256 KiB;
- не более 10 000 выполняемых строк;
- один `WAIT` не более 24 часов;
- сумма `WAIT` не более семи суток;
- Commander-строка не более 256 символов.

## Пример

```text
# Настройка видна целиком
AE0
AT0
AC2
ALU3
ALV0.2
A0
AE1

# Движение, ноль, PWM OFF
A0.2
WAIT 2
A0
WAIT 1
AE0
```

Используйте только команды, допустимые для установленной версии прошивки и конкретной механики.
FOCTwin не добавляет скрытый `AE0` после нормального завершения, поэтому безопасное окончание
должно быть явно записано в файле.

## Запуск

1. Подключите плату в разделе ручного управления.
2. Перейдите в **«Команды и программы» → «Программа»**.
3. Нажмите **«Открыть…»** и выберите `.focscript`/`.txt` либо вставьте текст вручную.
4. Нажмите **«Проверить программу»** и прочитайте развёрнутый список `TX`/`WAIT`.
5. Выберите папку журналов.
6. Нажмите **«Запустить»**. Любая правка текста требует повторной проверки.
7. Для досрочного завершения используйте **«Остановить»** или общий **«АВАРИЙНЫЙ СТОП»**.

Запуск блокируется без Serial, во время токового/фрикционного опыта и пока отправляется другая
очередь конфигурации. Команды отправляются последовательно с минимальным интервалом интерфейса
между соседними Serial-записями; `WAIT` не блокирует UI.

При ручной остановке, ошибке отправки или ошибке записи FOCTwin выполняет best-effort target zero
и `AE0`. При физически потерянном Serial доставить эти команды невозможно. После разрыва программа
получает статус `interrupted` и не возобновляется автоматически.

## Папка запуска

Каждый запуск создаёт уникальную подпапку вида
`YYYY-MM-DD_HH-MM-SS_<program>_<id>`:

| Файл | Содержимое |
|---|---|
| `program.focscript` | Точная копия выполненного исходника |
| `execution.jsonl` | Ordered events: start, commands, waits, ответы, stop/error, finish |
| `telemetry.csv` | Полные распознанные monitor samples во время запуска |
| `summary.json` | Статус, время, длительность, SHA-256 исходника, counts и пути |

`execution.jsonl` дописывается и синхронизируется с диском после каждого события;
`summary.json` заменяется атомарно. Успешная Serial-запись означает только, что строка передана
драйверу порта; отдельный ответ платы, если он есть, записывается следующим event.

Статусы: `completed`, `stopped`, `interrupted`, `failed` и `completed_with_errors`.

## Папки обмена

Значения по умолчанию:

```text
Документы\AutotunerExchange\inbox\programs
Документы\AutotunerExchange\outbox\runs
```

Первая папка лишь открывается в file picker как удобная отправная точка. Вторая задаётся в
интерфейсе явно. FOCTwin не наблюдает `inbox`, не запускает новые файлы и не подключается к Drive.

FolderBridge можно настроить на два независимых направления:

1. Google Drive → local `inbox\programs` для новых `.focscript`;
2. local `outbox\runs` → Google Drive для журналов и телеметрии.

Это сохраняет простой и проверяемый цикл, не давая сетевому транспорту доступа к мотору.
