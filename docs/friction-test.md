# Тест трения FOCTwin 0.3.1

## Что делает тест

Раздел «Идентификация» проводит четыре низкоскоростных движения в режиме SimpleFOC
`velocity + FOC Current`: `+0,02`, `-0,02`, `+0,05` и `-0,05 рад/с` по умолчанию. Для каждой
точки FOCTwin сначала ждёт стабилизации, затем отдельно накапливает полезное окно Iq, скорости
и координаты. Между точками цель возвращается в ноль; после серии PWM отключается.

На установившихся участках момент оценивается как `|Kt · Iq|`. Совместная аппроксимация двух
направлений даёт Coulomb+ и Coulomb−, их среднее и общий коэффициент вязкого трения. 95-й
процентиль тока на переходном участке используется только как грубая первая оценка момента
страгивания.

## Почему результат может быть отклонён

Стартовый предел тока равен 0,05 А. Если этого момента не хватает, FOCTwin завершит серию,
отметит точки как «скорость не достигнута» и не рассчитает пригодный набор коэффициентов.
Программа не повышает предел автоматически: после остановки пользователь может вручную задать
больший ток и при необходимости расширить остальные параметры плана. Значения опыта всё равно
не могут быть шире активных программных аварийных порогов FOCTwin; перед запуском приложение
показывает фактическую границу каждого параметра для подтверждения.

Точка также отклоняется при неверном направлении, большой ошибке слежения, нестабильной
скорости или недостатке отсчётов. Отрицательный коэффициент аппроксимации считается физически
непригодным. Даже валидный результат подписан как грубая оценка и переносится в профиль только
отдельной кнопкой.

## Автовосстановление и checkpoint

При остановке телеметрии FOCTwin отправляет цель 0 и повторный `AE0`, после чего штатный
watchdog восстанавливает monitor/DTR. Когда свежие данные снова появились и координата остаётся
в границах, программа повторно применяет конфигурацию опыта, включает PWM и начинает только
прерванную точку заново. Число попыток ограничено в настройках опыта.

После каждой завершённой точки сохраняется checkpoint. Если приложение или питание пришлось
перезапустить, откройте тот же проект, подключите мотор при выключенном PWM и нажмите
«Продолжить из checkpoint». Уже завершённые точки повторяться не будут.

Для каждого запуска проект хранит сырые CSV-файлы, запись эксперимента в SQLite и итоговый JSON
в папке `exports`. После нормального завершения или остановки ручная конфигурация
восстанавливается, но PWM остаётся выключенным.
