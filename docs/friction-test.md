# Тест трения FOCTwin 0.3.2

## Что делает тест

Раздел «Идентификация» проводит четыре низкоскоростных движения в режиме SimpleFOC
`velocity + Voltage torque`: `+0,02`, `-0,02`, `+0,05` и `-0,05 рад/с` по умолчанию. Такой
первичный опыт не зависит от ещё не идентифицированного внутреннего FOC Current. Благодаря
заданному в прошивке сопротивлению фазы ограничение `ALC` остаётся пределом выхода регулятора
скорости, а SimpleFOC преобразует его в ограниченную команду Uq. Между точками цель возвращается
в ноль; после серии PWM отключается.

Средняя скорость и её устойчивость оцениваются по наклону координаты в окне 0,5 с. Это не даёт
шумному мгновенному значению скорости отвергнуть фактически ровное движение. Эквивалентный ток
в Voltage torque восстанавливается из Uq, сопротивления фазы и противо-ЭДС; момент равен
`|Kt · Iэкв|`. Совместная аппроксимация двух направлений даёт Coulomb+ и Coulomb−, их среднее и
общий коэффициент вязкого трения. 95-й процентиль переходного Iэкв используется как грубая
первая оценка момента страгивания; измеренный Iq сохраняется отдельно для диагностики.

## Почему результат может быть отклонён

Стартовый предел тока равен 0,05 А. Если этого момента не хватает, FOCTwin завершит серию,
отметит точки как «скорость не достигнута» и не рассчитает пригодный набор коэффициентов.
Программа не повышает предел автоматически: после остановки пользователь может вручную задать
больший ток и при необходимости расширить остальные параметры плана. Значения опыта всё равно
не могут быть шире активных программных аварийных порогов FOCTwin; перед запуском приложение
показывает фактическую границу каждого параметра для подтверждения.

Точка также отклоняется при неверном направлении, большой ошибке слежения, нестабильном наклоне
координаты или недостатке отсчётов. Краткое превышение рабочего тока, напряжения или скорости
не завершает опыт: рабочий предел должен быть превышен в трёх последовательных отсчётах.
Двукратный выброс или выход координаты останавливают PWM сразу. Общий
программный SafetyGuard применяет то же подтверждение, поэтому один случайный отсчёт
не сможет обойти защиту опыта и сам по себе выключить PWM.
Отрицательный коэффициент аппроксимации считается физически непригодным. Даже валидный результат
подписан как грубая оценка и переносится в профиль только отдельной кнопкой.

## Автовосстановление и checkpoint

При остановке телеметрии FOCTwin отправляет цель 0 и повторный `AE0`, после чего штатный
watchdog восстанавливает monitor/DTR. Когда свежие данные снова появились и координата остаётся
в границах, программа повторно применяет конфигурацию опыта, включает PWM и начинает только
прерванную точку заново. Число попыток ограничено в настройках опыта.

После каждой завершённой точки сохраняется checkpoint. Если приложение или питание пришлось
перезапустить, откройте тот же проект, подключите мотор при выключенном PWM и нажмите
«Продолжить из checkpoint». Уже завершённые точки повторяться не будут. Checkpoint старого
опыта FOC Current намеренно не смешивается с результатами 0.3.2: для него нужно начать новую
серию.

Для каждого запуска проект хранит сырые CSV-файлы, запись эксперимента в SQLite и итоговый JSON
в папке `exports`. После нормального завершения или остановки ручная конфигурация
восстанавливается, но PWM остаётся выключенным.
