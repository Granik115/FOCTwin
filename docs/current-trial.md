# Один безопасный токовый опыт FOCTwin 0.5.0b3

Токовый опыт остаётся локальным инструментом раздела **«Доводка на моторе»**. Он не запускается
из `.focscript`, Google Drive или FolderBridge и требует отдельного видимого подтверждения.

## Что нажимать

1. Откройте или создайте проект FOCTwin.
2. Подключите плату и дождитесь свежей полной телеметрии.
3. Убедитесь, что PWM отключён, а координата находится внутри `±3 rad`.
4. Откройте **«Доводка на моторе»**.
5. Для первого запуска оставьте `0.01 A`, `P=0.4`, `I=40` и нажмите кнопку запуска.
6. Проверьте точный план в подтверждении и держите питание доступным.

Checkpoint, созданный до 0.4.2b3, несовместим с новыми пределами: начинайте новый опыт, чтобы
старые `0.1 A / P=8.4222 / I=814` не восстановились автоматически.

## Последовательность

1. При выключенном PWM записывается пассивный baseline current-sense не менее чем из 10 полных
   отсчётов. Peak `sqrt(Iq²+Id²) > 0.05 A` или ненулевой Uq/Ud завершает опыт без силовой команды.
2. Запоминается свежая исходная координата.
3. С PWM OFF настраивается сохранённый `Angle + Voltage`, эквивалентный Uq limit `3 V` и velocity
   limit `0.2 rad/s`.
4. PWM включается для прихода в исходную координату и проверки остановки.
5. При прямом `Torque + Voltage` выполняется current-sense preflight `0, +0.01, 0, -0.01 V`.
6. Только после правильного знака Iq и отсутствия доминирующего Id с PWM OFF задаются q/d
   `P=0.4`, `I=40`, `D=0`, LPF `0.005 s`, ramp `50 V/s`, target ceiling `0.1 A` и working
   voltage `2 V`.
7. `Torque + FOC Current` записывает `1 s` нуля, `2 s` шага `0.01 A` и `1 s` нуля.
8. PWM отключается, мотор возвращается к исходной координате, затем ручная конфигурация
   восстанавливается с PWM OFF.

Ток, напряжение, координата, velocity и свежесть телеметрии контролируются на всём опыте.
Нарушение вызывает best-effort stop.

## Результат и восстановление

Результат, CSV-сегменты и `*_SEND_ME.zip` сохраняются в выбранном проекте. Автоматической
публикации ZIP в FolderBridge больше нет; нужный файл или папку переносит пользователь либо
внешняя программа синхронизации.

При потере питания, Serial или телеметрии checkpoint сохраняется, а частичная попытка не считается
успешной. После возврата связи опыт может повториться со своей безопасной границы; после перезапуска
приложения продолжение выбирается пользователем вручную.
