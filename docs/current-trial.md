# Один безопасный токовый опыт FOCTwin 0.4.0

## Что нажимать

1. Откройте прежний проект FOCTwin или создайте новый.
2. Подключите плату и дождитесь свежей телеметрии.
3. Убедитесь, что PWM отключён и координата находится внутри `±3 рад`.
4. Откройте «Доводка на реальном моторе».
5. Для первого запуска не меняйте числа и нажмите большую кнопку запуска.
6. Подтвердите запуск и наблюдайте за статусом.

После завершения поле отчёта показывает один файл с суффиксом `_SEND_ME.zip`. Для анализа
достаточно передать только этот ZIP: в нём уже лежат JSON и все CSV-сегменты.

## Что программа делает сама

1. Запоминает свежую координату как исходную.
2. С отключённым PWM настраивает сохранённые позиционный и скоростной PID,
   `Angle + Voltage`, эквивалентный предел Uq `3 В` и скорость `0,2 рад/с`.
3. Включает PWM, приходит в исходную координату и проверяет остановку.
4. Отключает PWM, задаёт токовые Q/D `P=8,4222`, `I=814`, `D=0`, LPF `0,005 с`,
   ramp `3000 В/с`, лимит цели `0,5 А`, рабочее напряжение `12 В`.
5. Выбирает `Torque + FOC Current`, заранее задаёт `0 А` и только затем включает PWM.
6. Пишет `1 с` нуля, `2 с` ступени `0,1 А` и ещё `1 с` нуля.
7. Отключает PWM, возвращается к исходной координате, останавливается и снова отключает PWM.
8. Восстанавливает ручные настройки без включения PWM.

## Если отключить питание или выдернуть провод

- Доступная команде остановка отправляется немедленно, но при физически отсутствующей связи она
  не может гарантированно дойти до платы.
- Checkpoint сохраняется сразу.
- Через пять секунд без свежей телеметрии подаётся выбранный звуковой сигнал.
- FOCTwin продолжает переподключение; после ручного reset или возврата питания сначала отправляет
  `AE0`.
- Незавершённая попытка целиком исключается из метрик и повторяется с первого шага.
- Если закрыть приложение, следующий запуск можно продолжить кнопкой checkpoint; будет создан
  новый CSV-сегмент, а итоговый ZIP соберёт их вместе.

Если отключено только силовое питание мотора, но USB и плата продолжают передавать данные,
Serial-разрыва может не быть. Такой запуск завершится с пометкой об отсутствии измеренного отклика
Iq и не будет считаться пригодным для выбора коэффициентов.
